## 试题一参考答案：需求管理案例（第一/二批次）

> 考点：需求管理及控制流程 + 需求确认 + 需求状态跟踪
> 满分：25分

---

### 问题1参考答案（12分）

小张在需求管理及控制过程中存在的不足：

1. **需求分析缺乏深度和广度**：业务组分析完成后"马上"与用户确认，过于仓促，没有进行充分的需求调研和分析，导致需求深度不够。
2. **缺乏需求评审环节**：需求分析文档没有经过正式的评审（如同行评审、技术评审），直接交给实施组进行技术方案设计。
3. **二次确认不规范**："视情况"与用户进行二次沟通确认，而非强制要求，导致可能存在未经充分确认的需求。
4. **缺乏用户参与度管理**：上线后用户没有真正使用，说明缺乏用户培训和推广计划，没有让用户在开发过程中持续参与。
5. **缺乏测试和验收环节**：流程中没有提到系统测试、用户验收测试（UAT），导致上线后才发现BUG和业务流程缺失。
6. **缺乏需求基线管理**：没有建立需求基线，未明确哪些需求已经确认、冻结，哪些是变更。
7. **缺乏需求变更控制**：虽然预测到频繁变更，但流程中没有正式的变更控制委员会（CCB）审批环节。
8. **缺乏需求跟踪矩阵**：没有建立需求跟踪矩阵来确保每个需求都被实现和测试。

> 每点1.5-2分，答出6-8点即可得满分12分。

### 问题2参考答案（4分）

（1）**确认范围**（或"范围确认"、"需求确认"）

> 完整说法：由于缺乏**确认范围**中的**需求验证/可交付物的正式验收**，导致业务流程有缺失。

### 问题3参考答案（5分）

项目中需求可能存在的几种状态：

- **已提交**：需求已由用户或业务方提出，等待分析。
- **已分析**：需求已完成分析，形成需求文档。
- **已确认**：需求已与用户确认，达成一致。
- **已设计**：需求对应的技术方案已完成设计。
- **已实现**：需求对应的功能已完成开发。
- **已测试**：需求对应的功能已通过测试。
- **已验收**：需求已通过用户验收。
- **已变更**：需求发生了变更。
- **已关闭**：需求已完结（验收通过或被取消）。

> 每种状态1分，答出5种即可得满分5分。

### 问题4参考答案（4分）

改进建议：

1. **增加需求评审环节**：在需求分析完成后，组织业务组、实施组、开发组及关键用户进行正式的需求评审。
2. **建立需求基线和变更控制流程**：确认后的需求纳入基线管理，任何变更必须经过CCB审批。
3. **引入需求跟踪矩阵**：建立从需求到设计、开发、测试的双向追踪，确保需求完整覆盖。
4. **增加用户验收测试（UAT）**：在上线前组织用户进行验收测试，确保系统满足业务需求。
5. **加强用户培训和推广**：制定用户培训计划，确保用户能够正确使用系统。

> 每点1分，答出4点即可得满分4分。

## 试题二参考答案：PERT/EVM计算题（第三批次）

> 考试日期：2023-11-04
> 考点：β三点估算 + 关键路径 + 浮动时间 + 挣值分析（EVM）+ EAC预测
> 满分：25分

---

## 问题1参考答案（6分）

β分布三点估算公式：**期望工期 = (最乐观 + 4×最可能 + 最悲观) / 6**

- A = (1 + 4×2 + 3) / 6 = 12/6 = **2天**
- B = (1 + 4×3 + 5) / 6 = 18/6 = **3天**
- C = (0.8 + 4×2.8 + 6) / 6 = 18/6 = **3天**
- D = (5 + 4×7 + 9) / 6 = 42/6 = **7天**
- E = (1 + 4×2 + 3) / 6 = 12/6 = **2天**
- F = (2 + 4×4 + 6) / 6 = 24/6 = **4天**

> 每个活动1分，共6分。

## 问题2参考答案（4分）

- 路径2：A→C→E→F = 2+3+2+4 = **11天**

**关键路径：A→B→D→E→F**
**总工期：18天**

## 问题3参考答案（8分）

**① C超出1天（C工期变为4天）：**

- 路径1：A→B→D→E→F = 18天（不变）
- 路径2：A→C→E→F = 2+4+2+4 = 12天

C的总浮动 = 18 - 11 = 7天，超出1天后浮动还剩6天，不影响关键路径。

**工期不变，仍为18天，关键路径仍为A→B→D→E→F。**

**② C超出2天（C工期变为5天）：**

- 路径1：A→B→D→E→F = 18天（不变）
- 路径2：A→C→E→F = 2+5+2+4 = 13天

C的总浮动还有5天，仍不影响关键路径。

**工期不变，仍为18天，关键路径仍为A→B→D→E→F。**

> 每个小问4分：判断结论2分 + 计算过程2分。

## 问题4参考答案（4分）

**已知条件：**
- 第9天末，AC（实际成本）= 32万
- ABCD均已完成，E完成一半
- 每天每个活动花费2万

**计算PV（计划价值）：**

按最早开始时间安排进度计划：
- A：第1~2天（2天）
- B：第3~5天（3天）；C：第3~5天（3天）
- D：第6~12天（7天）
- 第9天末计划完成情况：A✓、B✓、C✓、D进行了4天（完成4/7）

PV = (2+3+3)×2 + 4×2 = 16 + 8 = **24万**

**计算EV（挣值）：**

ABCD均已完成，E完成一半：
- EV = (2+3+3+7)×2 + 2×2×0.5 = 30 + 2 = **32万**

**挣值指标：**

- **CV = EV - AC = 32 - 32 = 0万**（成本无偏差）
- **SV = EV - PV = 32 - 24 = +8万**（进度超前）

**绩效说明：** CV=0，项目成本恰好在预算内；SV>0，项目进度超前，实际完成工作量超过计划。

> CV计算1分、SV计算1分、绩效说明2分。

## 问题5参考答案（3分）

临时性偏差 → 后续按原计划执行，使用公式：**EAC = AC + (BAC - EV)**

BAC = 所有活动总预算 = (2+3+3+7+2+4) × 2 = 21 × 2 = **42万**

**EAC = 32 + (42 - 32) = 32 + 10 = 42万**

> 公式1分，BAC计算1分，EAC结果1分。

**公式速记：**
- 临时性偏差：EAC = AC + (BAC - EV)，即"花了多少 + 剩余按原价"
- 典型性偏差：EAC = BAC / CPI，即"按当前效率推算总成本"
