**第 4 题** 某项目当前状态：BAC = 400万，PV = 200万，EV = 160万，AC = 180万。以下说法正确的是？

A. SV = -20万，项目成本超支
B. CV = -20万，项目成本超支，SPI = 0.8，进度落后
C. SV = -40万，进度落后；CV = -20万，成本超支 ✅
D. CPI = 1.125，项目成本节约

**解析**：SV = EV - PV = 160 - 200 = -40万（进度落后）；CV = EV - AC = 160 - 180 = -20万（成本超支）；SPI = EV/PV = 160/200 = 0.8；CPI = EV/AC = 160/180 ≈ 0.89（成本超支，不是节约）。

**第 5 题** 以下关于质量成本（COQ）的说法，正确的是？

A. 预防成本和鉴定成本属于一致性成本，内部失败成本和外部失败成本属于非一致性成本 ✅
B. 预防成本越高，项目质量越差
C. 外部失败成本发生在产品交付前，内部失败成本发生在交付后
D. 质量成本越低，说明项目质量管理越好

**解析**：质量成本分两类：一致性成本（预防成本+鉴定成本，为避免失败而投入）和非一致性成本（内部失败成本+外部失败成本，失败后产生的代价）。外部失败成本发生在交付后（客户发现问题），内部失败成本发生在交付前（内部发现问题）。

**第 8 题** 某项目团队有8人，新增2名成员后，沟通渠道增加了多少条？

A. 2条
B. 9条
C. 17条 ✅
D. 18条

**解析**：沟通渠道公式 = N×(N-1)/2。原8人：8×7/2 = 28条；新增2人后10人：10×9/2 = 45条；增加 45 - 28 = 17条。

**第 53 题** 某项目当前状态：PV=100万，EV=80万，AC=90万。以下说法正确的是？

A. 项目进度超前，成本节省
B. 项目进度落后，成本超支 ✅
C. 项目进度落后，成本节省
D. 项目进度超前，成本超支

**解析**：SV = EV - PV = 80 - 100 = -20万（负数=进度落后）；CV = EV - AC = 80 - 90 = -10万（负数=成本超支）。SPI = 80/100 = 0.8 < 1（落后）；CPI = 80/90 ≈ 0.89 < 1（超支）。

B. 成本加激励费用合同（CPIF）中，如果实际成本低于目标成本，节省的费用全部归买方

**第 59 题** 以下关于项目沟通渠道数量的计算，说法正确的是？

A. 项目有10个干系人，沟通渠道数量为 10×9 = 90
B. 项目有10个干系人，沟通渠道数量为 10×(10-1)/2 = 45 ✅
C. 项目有10个干系人，沟通渠道数量为 10×(10+1)/2 = 55

**解析**：⚠️ 本题A和C均正确，出题有瑕疵，记答对。质量成本（COQ）分两大类：一致性成本（预防成本+评价/鉴定成本）和非一致性成本（内部失败成本+外部失败成本）。A正确：预防成本和评价成本都属于一致性成本。C也正确：内部失败成本（返工、报废）和外部失败成本（保修、退货）都属于非一致性成本（即不一致性成本，两种译法含义相同）。B错：返工是内部失败成本，不是预防成本。D错：提高预防成本通常会降低失败成本，总质量成本可能降低。
