## 二、信息与信息系统

### 2.1 信息的基本概念

**信息**是客观事物状态和运动特征的一种普遍形式，是客观世界中各种事物的变化和特征的最新反映，是客观事物之间相互联系和相互作用的表征。

信息的**主要特征**：

| 特征 | 说明 |
|------|------|
| **客观性** | 信息是客观存在的，不以人的意志为转移 |
| **普遍性** | 信息无处不在 |
| **无限性** | 信息资源是无限的 |
| **动态性** | 信息随时间变化而变化 |
| **相对性** | 不同主体从同一事物获取的信息量可能不同 |
| **依附性** | 信息依附于载体存在，但不等于载体本身 |
| **变换性** | 信息可以用不同方式表达 |
| **传递性** | 信息可以在时间和空间上传递 |
| **层次性** | 信息可以分层次 |
| **系统性** | 不同类别的信息可以形成信息系统 |
| **转化性** | 信息可以转化为物质或能量 |

> 记忆口诀：信息**不具有主观性**——信息本身是客观的，但人对信息的理解可以有差异，这是高频易错点。

### 2.2 信息系统

**信息系统**是由计算机硬件、网络和通信设备、计算机软件、信息资源、信息用户和规章制度组成的以处理信息流为目的的人机一体化系统。

信息系统的**五个基本功能**：输入、存储、处理、输出、控制。

### 2.3 信息化

**信息化**是指培育、发展以智能化工具为代表的新的生产力，并使之造福于社会的历史过程。

信息化的**核心**：信息资源的开发利用。

信息化体系的**六要素**：

| 要素 | 说明 |
|------|------|
| **信息资源** | 核心，是信息化的对象 |
| **信息网络** | 基础设施 |
| **信息技术应用** | 主阵地 |
| **信息技术和产业** | 物质基础 |
| **信息化人才** | 成功之本 |
| **信息化政策法规和标准规范** | 保障 |

> 记忆口诀：**资网应技人法**（资源、网络、应用、技术产业、人才、法规）

## 三、现代化基础设施

### 3.1 新型基础设施建设（新基建）

新型基础设施主要包括三个方面：

| 类型 | 内容 |
|------|------|
| **信息基础设施** | 5G、物联网、工业互联网、卫星互联网、人工智能、云计算、区块链等 |
| **融合基础设施** | 智能交通、智慧能源等 |
| **创新基础设施** | 重大科技基础设施、科教基础设施等 |

### 3.2 工业互联网

**工业互联网**是新一代信息通信技术与工业经济深度融合的新型基础设施、应用模式和工业生态。

工业互联网的**三大体系**：网络体系、平台体系、安全体系。

工业互联网的**三个核心功能**：数据采集、工业数据分析、工业应用创新。

### 3.3 车联网

**车联网**是以车内网、车际网和车载移动互联网为基础，按照约定的通信协议和数据交互标准，在车-X（X：车、路、行人及互联网等）之间进行无线通信和信息交换的大系统网络。

---

## 四、现代化创新发展

### 4.1 两化融合与智能制造

**两化融合**：信息化与工业化深度融合。

**智能制造**是基于新一代信息通信技术与先进制造技术深度融合，贯穿于设计、生产、管理、服务等制造活动的各个环节，具有自感知、自学习、自决策、自执行、自适应等功能的新型生产方式。

智能制造的**三个基本范式**：数字化制造、数字化网络化制造、数字化网络化智能化制造。

### 4.2 消费互联网

消费互联网以个人为用户，以日常生活为应用场景，核心是连接人与服务。

## 五、数字中国

### 5.1 数字经济

**数字经济**是以数字化的知识和信息作为关键生产要素，以现代信息网络作为重要载体，以信息通信技术的有效使用作为效率提升和经济结构优化的重要推动力的一系列经济活动。

数字经济的**四化框架**：数字产业化、产业数字化、数字化治理、数据价值化。

### 5.2 数字政府

**数字政府**是运用云计算、大数据、人工智能等新一代信息技术，以数据为核心资源，对政府的服务、管理、运行等进行数字化改造的新型政府形态。

### 5.3 数字社会

数字社会建设聚焦**民生服务**，推进教育、医疗、养老、就业等领域数字化。

### 5.4 数字生态

数字生态建设核心是**数据要素市场**，推进数据确权、定价、交易、流通。

## 六、数字化转型与元宇宙

### 6.1 数字化转型

**数字化转型**是利用新一代数字技术，对企业的战略、组织、运营、产品、服务等进行系统性变革，以实现业务创新和价值创造的过程。

数字化转型的**三个层次**：
- **数字化**：将模拟信息转化为数字信息
- **数字化升级**：利用数字技术优化现有业务
- **数字化转型**：以数字技术重构业务模式和价值创造方式

> 注意区分：数字化（digitization）→ 数字化升级（digitalization）→ 数字化转型（digital transformation），三者是递进关系。

### 6.2 元宇宙

**元宇宙**是整合多种新技术而产生的新型虚实相融的互联网应用和社会形态，它基于扩展现实技术提供沉浸式体验，基于数字孪生技术生成现实世界的镜像，基于区块链技术搭建经济体系。

元宇宙的**关键技术**：扩展现实（XR）、数字孪生、区块链、人工智能、5G/6G。

## 七、高频考点汇总

1. **信息的客观性**：信息本身是客观的，人对信息的理解有差异，但不能说信息具有主观性。
2. **信息化六要素**：资源（核心）、网络、应用、技术产业、人才、法规——口诀"资网应技人法"。
3. **新基建三类**：信息基础设施、融合基础设施、创新基础设施。
4. **工业互联网三大体系**：网络体系、平台体系、安全体系。
5. **数字经济四化**：数字产业化、产业数字化、数字化治理、数据价值化。
6. **两化融合**：信息化与工业化，不是"数字化与工业化"。
7. **智能制造三范式**：数字化→数字化网络化→数字化网络化智能化，是递进关系。
8. **数字化转型三层次**：数字化→数字化升级→数字化转型，层层递进。

---

## 八、易错点

- ❌ 信息具有主观性 → ✅ 信息具有**客观性**，人对信息的理解才有差异
- ❌ 信息化的核心是信息网络 → ✅ 信息化的核心是**信息资源**的开发利用
- ❌ 两化融合是数字化与工业化 → ✅ 两化融合是**信息化**与工业化
- ❌ 数字化转型就是数字化 → ✅ 数字化转型是最高层次，包含业务模式重构
- ❌ 工业互联网只是工业领域的互联网 → ✅ 工业互联网是新型基础设施，有三大体系
- ❌ 元宇宙的核心技术只有VR → ✅ 元宇宙涉及XR、数字孪生、区块链、AI、5G等多项技术

**第 1 题** 以下关于信息特征的说法，正确的是？

A. 信息具有主观性，因为不同的人对同一信息的理解不同
B. 信息具有客观性，是客观事物状态和运动特征的普遍形式 ✅
C. 信息具有排他性，一旦被某人使用，其他人就无法再使用
D. 信息的价值是固定不变的，不会随时间和环境变化

**解析**：信息本身是客观的，人对信息的理解有差异，但不能说信息具有主观性。A 是最高频陷阱。

**第 2 题** 信息化体系六要素中，被认为是核心的是？

A. 信息网络
B. 信息技术和产业
C. 信息资源 ✅
D. 信息化人才

**解析**：信息资源是信息化六要素的核心，信息网络是基础设施，人才是成功之本。

A. 新基建分为：数字基础设施、物理基础设施、融合基础设施
B. 新基建分为：信息基础设施、融合基础设施、创新基础设施 ✅

**第 4 题** 数字经济的"四化框架"包括哪四个方面？

A. 数字产业化、产业数字化、数字化治理、数据价值化 ✅
B. 数字产业化、产业数字化、政府数字化、社会数字化
C. 信息产业化、产业信息化、数字化治理、数据资产化

**第 5 题** 某企业正在推进信息化建设，将原有纸质档案全部扫描存储为电子文件，并上线了一套文档管理系统。以下对该企业所处数字化阶段的判断，正确的是？

A. 该企业已完成数字化转型
B. 该企业处于数字化升级阶段 ✅
C. 该企业处于数字化阶段，尚未完成数字化升级
D. 该企业已进入元宇宙应用阶段

**解析**：扫描存档+上线管理系统，已在利用数字技术优化现有业务，属于数字化升级阶段。未重构业务模式，不是转型。
