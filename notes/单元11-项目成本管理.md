## 一、项目成本管理概述

**项目成本管理**解决的核心问题：**确保项目在批准的预算内完成**。成本管理与进度管理共享EVM挣值分析体系，是高项考试中计算题的另一个重灾区。

成本管理共有 **4 个过程**：

| 过程组 | 成本管理过程 |
|------|------|
| 规划 | ① 规划成本管理 ② 估算成本 ③ 制定预算 |
| 监控 | ④ 控制成本 |

> 记忆要点：成本管理**规划3个，监控1个**，共4个过程，是过程数量最少的知识域之一。

---

## 二、规划成本管理

**规划成本管理**是为规划、管理、花费和控制项目成本而制定政策、程序和文档的过程。

- **过程组**：规划过程组
- **核心输出**：**成本管理计划**

**成本管理计划**规定了：
- 使用哪种估算方法（类比、参数、自下而上等）
- 成本偏差的容忍阈值（如CPI低于多少触发预警）
- 成本报告的格式和周期
- 货币单位和精度要求

> 记忆要点：规划成本管理的唯一核心输出是**成本管理计划**，与规划进度管理类似，它是后续所有成本过程的"规则手册"。

---

## 三、估算成本

### 3.1 成本估算方法

| 方法 | 说明 | 精度 | 适用阶段 |
|------|------|------|---------|
| **类比估算** | 参考类似项目历史数据 | 低（-25%～+75%） | 项目早期 |
| **参数估算** | 用统计模型（单价×数量） | 中 | 有历史数据时 |
| **自下而上估算** | 从最底层工作包逐级汇总 | 高（-5%～+10%） | 详细规划阶段 |
| **三点估算** | (O+4M+P)/6 | 中高 | 不确定性高时 |

> 记忆要点：**自下而上估算**精度最高，但耗时最长；**类比估算**最快但精度最低。

### 3.2 成本类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **直接成本** | 可直接归属于项目的成本 | 项目人员工资、设备采购 |
| **间接成本** | 多个项目共同分摊的成本 | 办公室租金、管理费用 |
| **固定成本** | 不随工作量变化的成本 | 设备租赁费 |
| **变动成本** | 随工作量变化的成本 | 材料费、加班费 |
| **沉没成本** | 已发生、无法收回的成本 | 已支付的不可退款费用 |

> ⚠️ **高频考点**：**沉没成本**不应影响未来决策，这是项目管理的基本原则。

## 四、制定预算

### 4.1 成本基准（S曲线）

**成本基准**是经批准的分时段项目预算，不包括管理储备，是EVM的基础。

$$成本基准 = \sum 各工作包成本估算 + 应急储备$$

**成本基准的形状**：随时间累积呈**S形曲线**（项目初期和末期花费少，中期花费多）。

### 4.2 项目预算的构成

$$项目总预算（BAC）= 成本基准 + 管理储备$$

| 组成部分 | 说明 | 审批权限 |
|---------|------|---------|
| **工作包成本估算** | 各工作包的直接成本 | 项目经理 |
| **应急储备（CR）** | 应对已识别风险（已知-未知风险） | 项目经理 |
| **管理储备（MR）** | 应对未识别风险（未知-未知风险） | 高层管理者 |

> ⚠️ **高频考点**：
> - **应急储备**在成本基准内，应对**已知风险**，项目经理可动用
> - **管理储备**在成本基准外（不在PMB中），应对**未知风险**，需高层批准才能动用

## 五、控制成本与EVM

### 5.1 EVM核心参数回顾

| 参数 | 全称 | 计算方式 |
|------|------|---------|
| **BAC** | 完工预算 | 项目总预算（不含管理储备） |
| **PV** | 计划价值 | 计划完成% × BAC |
| **EV** | 挣值 | 实际完成% × BAC |
| **AC** | 实际成本 | 实际花费的金额 |

### 5.2 EVM六公式（与进度管理共用）

| 公式 | 名称 | 含义 |
|------|------|------|
| **SV = EV - PV** | 进度偏差 | >0超前，<0落后 |
| **CV = EV - AC** | 成本偏差 | >0节省，<0超支 |
| **SPI = EV / PV** | 进度绩效指数 | >1超前，<1落后 |
| **CPI = EV / AC** | 成本绩效指数 | >1节省，<1超支 |
| **EAC = BAC / CPI** | 完工估算 | 预测最终总成本 |
| **VAC = BAC - EAC** | 完工偏差 | >0节省，<0超支 |

### 5.3 完工尚需估算（ETC）

$$ETC = EAC - AC$$

> ETC是从现在到项目完工还需要花费的成本。

### 5.4 完整EVM计算示例

> 某项目总预算BAC=500万，目前计划完成50%，实际完成40%，实际花费220万。

- **PV** = 500 × 50% = **250万**
- **EV** = 500 × 40% = **200万**
- **AC** = **220万**
- **SV** = 200 - 250 = **-50万**（进度落后）
- **CV** = 200 - 220 = **-20万**（成本超支）
- **SPI** = 200 / 250 = **0.8**（进度落后）
- **CPI** = 200 / 220 = **0.909**（成本超支）
- **EAC** = 500 / 0.909 ≈ **550万**（预测完工总成本）
- **VAC** = 500 - 550 = **-50万**（预测超支50万）
- **ETC** = 550 - 220 = **330万**（还需花费330万）

## 六、成本管理的其他重要概念

### 6.1 生命周期成本

**生命周期成本**：项目从启动到最终处置的全部成本，包括开发成本、运营成本、维护成本和处置成本。

> 记忆要点：项目决策时应考虑**生命周期成本**，而不仅仅是开发成本。

### 6.2 价值工程（VE）

**价值工程**：在保证功能不变的前提下，通过改进设计、工艺或材料来降低成本的方法。

$$价值 = \frac{功能}{成本}$$

提高价值的途径：提高功能、降低成本、或两者同时改善。

### 6.3 挣值管理的局限性

- EVM只反映**过去**的绩效，不能预测未来的风险
- CPI在项目完成20%后趋于稳定，可用于预测完工成本
- EVM需要有明确的WBS和成本基准才能有效运作

## 七、高频考点汇总

1. **成本管理4个过程**：规划3个（规划/估算/制定预算）+ 监控1个（控制成本）。
2. **应急储备 vs 管理储备**：应急储备在成本基准内（项目经理可用），管理储备在成本基准外（需高层批准）。
3. **自下而上估算精度最高**，类比估算最快但精度最低。
4. **沉没成本不影响决策**：已发生的不可回收成本不应影响未来决策。
5. **EVM六公式**：SV=EV-PV，CV=EV-AC，SPI=EV/PV，CPI=EV/AC，EAC=BAC/CPI，VAC=BAC-EAC。
6. **ETC = EAC - AC**：完工尚需估算，从现在到完工还需花多少钱。
7. **成本基准呈S形曲线**，不包含管理储备；项目总预算 = 成本基准 + 管理储备。

---

## 八、易错点

- ❌ 管理储备在成本基准内 → ✅ 管理储备在**成本基准外**，需高层批准才能动用
- ❌ 应急储备应对未知风险 → ✅ 应急储备应对**已知风险**（已识别的风险），管理储备才应对未知风险
- ❌ 沉没成本应该纳入决策考量 → ✅ **沉没成本不影响决策**，已花出去的钱不能收回
- ❌ 类比估算精度最高 → ✅ **自下而上估算**精度最高，类比估算精度最低
- ❌ EAC是已花费的成本 → ✅ EAC是**完工估算**，预测项目最终总成本；AC才是已花费成本
- ❌ BAC包含管理储备 → ✅ EVM中的BAC通常指**成本基准**（不含管理储备）

**第 1 题** 某项目在执行过程中遇到了一个此前已识别并制定了应对计划的风险，项目经理需要动用储备资金来应对。以下说法正确的是？

A. 项目经理应动用管理储备，因为管理储备专门用于应对风险事件
B. 项目经理应动用应急储备，因为应急储备用于应对已识别风险，且在成本基准内，项目经理可直接动用 ✅
C. 项目经理应动用管理储备，并向高层申请审批
D. 项目经理应动用应急储备，但需要向高层申请审批后才能使用

**解析**：**应急储备**用于应对已识别风险（已知-未知风险），包含在成本基准内，项目经理可直接动用，无需高层审批。**管理储备**用于应对未识别风险（未知-未知风险），在成本基准外，需高层批准。

**第 2 题** 以下关于项目总预算构成的说法，正确的是？

A. 项目总预算 = 工作包成本估算之和，不包含任何储备
B. 项目总预算 = 成本基准，成本基准包含应急储备和管理储备
C. 项目总预算 = 成本基准 + 管理储备，成本基准包含应急储备但不含管理储备 ✅
D. 项目总预算 = 工作包成本估算 + 管理储备，不包含应急储备

**解析**：**成本基准 = 工作包成本估算 + 应急储备**（不含管理储备）；**项目总预算 = 成本基准 + 管理储备**。管理储备在成本基准之外，EVM中的BAC对应成本基准，不含管理储备。

**第 3 题** 某项目已投入研发费用300万元，目前评估发现继续推进需再投入500万，但预期收益仅400万。项目发起人认为"已经花了300万，不能白费"，坚持继续推进。以下关于这种决策思路的说法，正确的是？

A. 发起人的判断是正确的，已投入的300万应纳入决策考量
B. 发起人的判断是错误的，已投入的300万属于沉没成本，不应影响未来决策 ✅
C. 发起人的判断是正确的，项目管理要求最大化已有投资的回报
D. 发起人的判断是错误的，应该将300万计入未来成本重新评估

**解析**：**沉没成本**是已发生且无法收回的成本，不应影响未来决策。正确的决策逻辑是：继续投入500万，收益仅400万，净亏损100万，应终止项目。"已花了300万不能白费"是典型的沉没成本谬误。

**第 4 题** 以下关于成本估算方法的说法，正确的是？

A. 类比估算精度最高，适合在项目详细规划阶段使用
B. 自下而上估算耗时最长，但精度最高，适合详细规划阶段 ✅
C. 参数估算不需要任何历史数据，可在项目任何阶段使用
D. 三点估算与PERT公式无关，是一种独立的成本估算方法

**解析**：**自下而上估算**从最底层工作包逐级汇总，精度最高（-5%～+10%），但最耗时，适合详细规划阶段。类比估算精度最低（-25%～+75%），适合项目早期快速估算。参数估算需要历史数据建立统计模型。三点估算就是PERT公式的应用。

**第 5 题（计算题）** 某项目总预算BAC=400万元，计划完成50%，实际完成45%，实际花费190万元。

- PV = 400×50% = **200万元**
- EV = 400×45% = **180万元**
- AC = **190万元**
- SV = EV-PV = 180-200 = **-20万元**（进度落后）
- CV = EV-AC = 180-190 = **-10万元**（成本超支）
- SPI = EV/PV = 180/200 = **0.9**（<1，进度落后）
- CPI = EV/AC = 180/190 ≈ **0.947**（<1，成本超支）
- EAC = BAC/CPI = 400/0.947 ≈ **422万元**
- VAC = BAC-EAC = 400-422 = **-22万元**（预测超支）
- ETC = EAC-AC = 422-190 = **232万元** ✅

**解析**：项目进度落后（实际完成45%，计划50%），成本超支（花了190万但只完成了价值180万的工作）。预测完工总成本约422万，超出预算约22万，还需花费约232万才能完工。

---

**第 6 题（计算题）** 某项目总预算BAC=300万元，应急储备30万元，管理储备20万元，CPI=0.9，AC=120万元。

(1) 成本基准 = 总预算 - 管理储备 = 300 - 20 = **280万元**（含应急储备30万）

(2) EAC = BAC/CPI = 300/0.9 ≈ **333万元**

(3) VAC = BAC - EAC = 300 - 333 = **-33万元**，预测超支**33万元** ✅

**解析**：成本基准不含管理储备，故成本基准=300-20=280万。EVM中BAC通常取成本基准，但本题明确给出总预算300万作为BAC，故EAC=300/0.9≈333万。VAC=BAC-EAC（注意：不是EAC-AC），结果为-33万，说明预测超支33万。
