## 一、组织通用治理概述

**组织通用治理**涵盖公司治理结构、内部控制、审计与合规等内容，是高项考试中偏"管理学"的章节。

本章考点相对集中，重点在于：**公司治理四层结构**、**内部控制五要素**、**审计的分类**。选择题会考具体概念的辨析，案例题偶尔会考"某公司缺少哪个内部控制要素"。

> 记忆口诀：**治理靠结构，控制靠五素，审计分内外**。

---

## 二、公司治理

### 2.1 公司治理的定义

**公司治理（Corporate Governance）**是指通过一套制度安排，协调股东、董事会、管理层和其他利益相关者之间的关系，以实现公司目标、防范风险、保护股东权益。

> 治理 ≠ 管理：治理是"决定做什么"（战略层），管理是"如何做"（执行层）。这是高频易错点。

### 2.2 公司治理四层结构

| 层级 | 机构 | 职责 |
|------|------|------|
| **第一层** | **股东会（股东大会）** | 公司最高权力机构，决定重大事项（增资、合并、解散等） |
| **第二层** | **董事会** | 对股东会负责，制定战略、监督管理层、任免高管 |
| **第三层** | **监事会** | 对股东会负责，监督董事会和管理层，独立于董事会 |
| **第四层** | **管理层（经理层）** | 对董事会负责，负责日常经营管理 |

> 记忆口诀：**股东会最大，董事会定战略，监事会来监督，管理层来执行**。
>
> 易错点：监事会和董事会是**平行关系**，监事会监督董事会，两者都对股东会负责，不存在上下级关系。

### 2.3 董事会的职责

- 制定公司战略目标和经营方针
- 任免公司高级管理人员（CEO、CFO等）
- 审批重大投资和财务决策
- 建立和维护内部控制体系
- 向股东会报告工作

### 2.4 独立董事制度

**独立董事**是指不在公司担任除董事外的其他职务，且与公司及其主要股东不存在可能妨碍其独立客观判断关系的董事。

作用：防止大股东操控董事会，保护中小股东利益，提高公司治理透明度。

## 三、内部控制

### 3.1 内部控制的定义

**内部控制**是由企业董事会、监事会、管理层和全体员工共同实施的，旨在实现控制目标的过程。

内部控制的**五个目标**：
- 经营的效率和效果
- 财务报告的可靠性
- 法律法规的遵循
- 资产的安全
- 战略目标的实现

### 3.2 内部控制五要素（COSO框架）

这是本章最核心的考点，五要素必须全部记住：

| 要素 | 说明 | 关键词 |
|------|------|--------|
| **① 控制环境** | 内部控制的基础，包括诚信价值观、组织结构、权责分配、人力资源政策等 | 基础、文化、氛围 |
| **② 风险评估** | 识别和分析实现目标过程中的相关风险，确定风险应对方式 | 识别风险、分析风险 |
| **③ 控制活动** | 确保管理层指令得以执行的政策和程序，如审批、授权、核对、盘点等 | 具体措施、执行层面 |
| **④ 信息与沟通** | 识别、获取和传递信息，使员工能够履行职责 | 信息传递、沟通机制 |
| **⑤ 监督活动** | 评估内部控制的质量，包括持续监督和专项评估 | 评估、改进 |

> 记忆口诀：**环境→评估→活动→沟通→监督**，从基础到执行到反馈，形成完整闭环。
>
> 英文缩写：COSO（Committee of Sponsoring Organizations）框架，考试中可能出现。

### 3.3 控制活动的主要类型

| 类型 | 说明 |
|------|------|
| **授权审批** | 重要业务须经授权人员审批 |
| **职责分离** | 不相容职务由不同人员担任（如记账与出纳分离） |
| **会计系统控制** | 确保交易被正确记录和报告 |
| **实物控制** | 对资产实施物理保护（门禁、保险柜等） |
| **绩效考核** | 将实际结果与预算/计划对比 |
| **信息处理控制** | 确保信息系统的准确性和完整性 |

> 职责分离是最重要的控制活动，考试中"出纳不能兼任会计"是经典例子。

## 四、审计

### 4.1 审计的定义与目的

**审计**是由独立的审计人员，对被审计单位的财务报告或其他信息进行系统检查和评价，以确定其是否符合既定标准，并向利益相关者报告结论的过程。

### 4.2 审计的分类

**按审计主体分类：**

| 类型 | 执行主体 | 特点 |
|------|---------|------|
| **内部审计** | 企业内部审计部门 | 服务于管理层，关注运营效率和内部控制有效性 |
| **外部审计** | 独立的会计师事务所 | 服务于股东和公众，关注财务报告的公允性 |
| **政府审计** | 国家审计机关（审计署） | 对国有资产和财政资金进行监督 |

**按审计内容分类：**

| 类型 | 说明 |
|------|------|
| **财务审计** | 审查财务报表是否公允反映财务状况 |
| **合规审计** | 审查是否遵守法律法规和内部政策 |
| **绩效审计（运营审计）** | 审查经营活动的效率和效果 |
| **信息系统审计** | 审查IT系统的安全性、可靠性和有效性 |

### 4.3 内部审计 vs 外部审计

| 维度 | 内部审计 | 外部审计 |
|------|---------|---------|
| **独立性** | 相对独立（对董事会/审计委员会负责） | 完全独立（第三方） |
| **目的** | 改善运营、强化内控 | 对财务报表发表意见 |
| **报告对象** | 管理层、董事会 | 股东、公众、监管机构 |
| **法律要求** | 非强制（上市公司建议设立） | 上市公司强制要求 |

## 五、IT治理

### 5.1 IT治理的定义

**IT治理**是公司治理的组成部分，确保IT战略与业务战略对齐，IT投资创造价值，IT风险得到有效管理。

### 5.2 IT治理框架

| 框架 | 全称 | 核心内容 |
|------|------|---------|
| **COBIT** | 信息和相关技术控制目标 | IT治理和管理的综合框架，覆盖规划、建设、运营、监控四个域 |
| **ITIL** | IT基础架构库 | IT服务管理最佳实践，关注服务交付和支持 |
| **ISO 27001** | 信息安全管理体系标准 | 信息安全管理的国际标准 |

### 5.3 IT治理的五个焦点领域

| 焦点 | 说明 |
|------|------|
| **战略对齐** | IT战略与业务战略保持一致 |
| **价值交付** | IT投资实现预期价值 |
| **风险管理** | 识别和管理IT相关风险 |
| **资源管理** | 优化IT资源（人员、应用、基础设施、信息）的使用 |
| **绩效测量** | 跟踪和监控IT绩效 |

## 六、高频考点汇总

1. **治理 vs 管理**：治理是"决定做什么"（战略层），管理是"如何做"（执行层），两者不能混淆。
2. **四层治理结构**：股东会（最高权力）→ 董事会（战略决策）→ 监事会（监督）→ 管理层（执行），监事会与董事会平行。
3. **内部控制五要素**：控制环境→风险评估→控制活动→信息与沟通→监督活动，缺一不可。
4. **职责分离**：最重要的控制活动，不相容职务必须分离（出纳不兼会计）。
5. **内部审计 vs 外部审计**：内部审计服务管理层，外部审计服务股东/公众，外部审计上市公司强制要求。
6. **COBIT**：IT治理的综合框架；**ITIL**：IT服务管理最佳实践，两者定位不同。

---

## 七、易错点

- ❌ 监事会对董事会负责 → ✅ 监事会和董事会都对**股东会**负责，两者是平行关系，监事会监督董事会
- ❌ 内部控制只是财务部门的事 → ✅ 内部控制由**全体员工**共同实施，不只是财务部门
- ❌ 内部控制五要素中"控制活动"是最基础的 → ✅ **控制环境**才是内部控制的基础，控制活动是具体执行层面
- ❌ 内部审计和外部审计目的相同 → ✅ 内部审计目的是改善运营和强化内控，外部审计目的是对财务报表发表独立意见
- ❌ COBIT 和 ITIL 是同一类框架 → ✅ COBIT 是 IT 治理框架（覆盖更广），ITIL 是 IT 服务管理最佳实践（聚焦服务交付）

**第 1 题** 以下关于公司治理四层结构的说法，正确的是？

A. 监事会对董事会负责，负责监督董事会的工作
B. 董事会是公司最高权力机构，有权决定公司合并、解散等重大事项
C. 监事会与董事会是平行关系，两者都对股东会负责 ✅
D. 管理层直接对股东会负责，执行股东会的决议

**解析**：监事会与董事会是平行关系，两者都直接对股东会负责，监事会负责监督董事会和管理层，但不是董事会的下级。A 错误，监事会对股东会负责，不是对董事会负责；B 错误，股东会才是最高权力机构；D 错误，管理层对董事会负责，不是直接对股东会负责。

**第 2 题** 某公司在梳理内部控制体系时，发现公司高层管理者缺乏诚信意识，导致员工普遍存在违规操作的现象。从内部控制五要素的角度看，该公司最根本的问题出在哪个要素上？

A. 控制活动
B. 风险评估
C. 监督活动
D. 控制环境 ✅

**解析**：高层管理者缺乏诚信意识、员工普遍违规，这是控制环境出了问题。控制环境是内部控制的基础，包括诚信价值观、组织文化、权责分配等，基础不牢则其他四个要素都会失效。控制活动是具体执行措施，风险评估是识别风险，监督活动是评估内控质量，都不是根本问题所在。

**第 3 题** 以下哪项属于内部控制"控制活动"要素中"职责分离"原则的正确应用？

A. 公司定期对仓库物资进行盘点，确保账实相符
B. 出纳负责现金收付，会计负责账务记录，两者由不同人员担任 ✅
C. 公司建立风险识别机制，定期评估经营风险
D. 内部审计部门每季度对各部门进行合规检查

**解析**：出纳负责现金收付、会计负责账务记录，两者由不同人员担任，这是职责分离的经典应用，属于控制活动要素。A 是实物控制（盘点）；C 是风险评估要素；D 是监督活动要素。

**第 4 题** 某上市公司聘请某会计师事务所对其年度财务报告进行审计，并向股东和监管机构出具审计意见。这属于哪种审计类型？

A. 内部审计
B. 政府审计
C. 绩效审计
D. 外部审计 ✅

**解析**：由独立的会计师事务所对上市公司财务报告进行审计，向股东和监管机构出具意见，这是标准的外部审计。外部审计的特征是：执行主体为独立第三方（会计师事务所），服务对象是股东和公众，上市公司强制要求。

**第 5 题** 以下关于 COBIT 和 ITIL 的说法，正确的是？

A. COBIT 和 ITIL 都是 IT 服务管理的最佳实践框架，功能相同
B. COBIT 是 IT 治理的综合框架，覆盖规划、建设、运营、监控；ITIL 聚焦 IT 服务交付和支持 ✅
C. ITIL 是 IT 治理框架，COBIT 是 IT 服务管理框架，两者定位相反
D. COBIT 只适用于大型企业，ITIL 适用于所有规模的企业

**解析**：COBIT 是 IT 治理的综合框架，覆盖规划、建设、运营、监控四个域，范围更广；ITIL 是 IT 服务管理的最佳实践，聚焦服务交付和支持，范围更聚焦。两者定位不同，可以互补使用。A 错误，两者功能不同；C 把两者定位说反了；D 是无中生有的干扰项。

**第 6 题** 某公司财务部门在月末对账时发现账目存在差异，经查是由于某员工同时担任出纳和会计两个职务，导致自行篡改账目。从内部控制角度分析，该公司违反了哪个控制原则，应归属于内部控制五要素中的哪个要素？

A. 违反了授权审批原则，属于控制活动要素
B. 违反了职责分离原则，属于控制活动要素 ✅
C. 违反了信息透明原则，属于信息与沟通要素
D. 违反了风险识别原则，属于风险评估要素

**解析**：一人同时担任出纳和会计，违反了职责分离原则——不相容职务必须由不同人员担任，这属于控制活动要素。职责分离是控制活动中最重要的手段，正是为了防止一人同时控制一笔交易的全过程而产生舞弊机会。
