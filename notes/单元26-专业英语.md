## 一、概述

本单元考查**项目管理专业英语**，主要包括：高频缩写的全称与中文含义、英文术语的准确理解、以及英文语境下的概念辨析。考试通常以**选择题**形式出现，给出英文缩写或术语，判断其含义；或给出中文概念，选出对应的英文表达。

> 本单元是"了解"级别，结合前25个单元积累的专业名词辞典，复习效率极高。

## 四、高频易混淆缩写辨析

### 4.1 形近易混组

| 组别 | 辨析 |
|------|------|
| **SV vs CV** | SV = Schedule Variance（进度偏差）；CV = Cost Variance（成本偏差）。S对应Schedule，C对应Cost |
| **SPI vs CPI** | SPI = Schedule Performance Index；CPI = Cost Performance Index。同上规律 |
| **EAC vs ETC** | EAC = Estimate **at** Completion（完工估算，总花多少）；ETC = Estimate **to** Complete（还需花多少） |
| **FCA vs PCA** | FCA = **Functional** Configuration Audit（功能配置审计）；PCA = **Physical** Configuration Audit（物理配置审计） |
| **IDS vs IPS** | IDS = Intrusion **Detection**（检测，发现入侵）；IPS = Intrusion **Prevention**（防御，阻止入侵） |
| **DAC vs MAC vs RBAC** | DAC = 自主（用户自己控制）；MAC = 强制（系统强制控制）；RBAC = 基于角色（按角色分配权限） |

### 4.2 中文相近但英文不同

| 中文 | 英文缩写 | 区别 |
|------|---------|------|
| 完工预算 | **BAC**（Budget at Completion） | 计划总花多少 |
| 完工估算 | **EAC**（Estimate at Completion） | 预计实际总花多少 |
| 完工尚需估算 | **ETC**（Estimate to Complete） | 还需花多少 |
| 完工偏差 | **VAC**（Variance at Completion） | BAC - EAC |
| 进度偏差 | **SV**（Schedule Variance） | EV - PV |
| 成本偏差 | **CV**（Cost Variance） | EV - AC |

### 4.3 同义/近义缩写

| 缩写1 | 缩写2 | 说明 |
|------|------|------|
| **RACI** | **RAM** | 都指责任分配矩阵，RACI是具体格式，RAM是通用名称 |
| **WBS** | — | 工作分解结构，注意WBS分解的是**可交付成果**，不是活动 |
| **OBS** | — | 组织分解结构，与WBS结合生成RAM |

## 六、高频考点汇总

1. **EVM六公式英文**：SV=EV-PV，CV=EV-AC，SPI=EV/PV，CPI=EV/AC，EAC=BAC/CPI，VAC=BAC-EAC。
2. **WBS全称**：Work Breakdown Structure，分解的是**可交付成果（Deliverable）**，不是活动。
3. **RACI四字母含义**：Responsible（执行）、Accountable（负责）、Consulted（咨询）、Informed（知情）。
4. **IaaS/PaaS/SaaS层次**：从底到上，IaaS提供硬件，PaaS提供平台，SaaS提供软件。
5. **Fast Tracking vs Crashing**：快速跟进增加风险，赶工增加成本，两者都只对关键路径有效。
6. **Contingency vs Management Reserve**：应急储备在基准内（已知风险），管理储备在基准外（未知风险）。

---

## 七、易错点

- ❌ SV是成本偏差 → ✅ SV是**进度**偏差（Schedule Variance），CV才是成本偏差
- ❌ EAC是还需花多少 → ✅ EAC是完工估算（总共花多少），**ETC**才是还需花多少
- ❌ WBS分解的是活动 → ✅ WBS分解的是**可交付成果**，活动分解来自活动清单
- ❌ RACI中A（Accountable）是执行者 → ✅ A是**负责人**（最终负责），R（Responsible）才是执行者
- ❌ Fast Tracking是增加资源 → ✅ Fast Tracking是串行改并行；增加资源是**Crashing（赶工）**
- ❌ 管理储备在成本基准内 → ✅ 管理储备在成本基准**外**，需高层批准才能动用

## 八、练习题记录

**第 1 题** 以下关于EVM挣值管理缩写的说法，正确的是？

A. SV = EV - PV，SV > 0 表示成本超支
B. CV = EV - AC，CV < 0 表示成本超支 ✅
C. SPI = EV / PV，SPI > 1 表示成本节约
D. CPI = AC / EV，CPI > 1 表示进度超前

**解析**：CV（成本偏差）= EV - AC，负数说明实际花费超过挣值，即成本超支。SV（进度偏差）= EV - PV，负数说明进度落后。CPI = EV/AC（不是AC/EV）。

---

**第 2 题** 某项目总预算 BAC = 500万，目前计划完成60%，实际完成50%，实际花费280万。以下说法正确的是？

A. PV = 250万，EV = 300万，项目进度超前
B. PV = 300万，EV = 250万，项目进度落后 ✅
C. PV = 300万，EV = 250万，项目成本节约
D. PV = 250万，EV = 300万，项目成本超支

**解析**：PV = 500×60% = 300万；EV = 500×50% = 250万；AC = 280万。SV = EV-PV = -50万（进度落后），CV = EV-AC = -30万（成本超支）。B正确（进度落后），C错误（成本也超支）。

**第 3 题** 在RACI矩阵中，"A"代表的角色含义是？

A. 负责执行任务的人（Responsible）
B. 对任务结果负最终责任的人（Accountable） ✅
C. 需要被咨询意见的人（Consulted）
D. 需要被告知进展的人（Informed）

**解析**：RACI = Responsible（执行者）、Accountable（最终负责人）、Consulted（被咨询者）、Informed（被告知者）。每项任务A只能有一个人，R可以有多个。

**第 4 题** 项目进度落后，项目经理决定将原本顺序执行的两个活动改为并行执行，这种技术称为？

A. Crashing（赶工）
B. Resource Leveling（资源平衡）
C. Fast Tracking（快速跟进） ✅
D. Schedule Compression（进度压缩）

**解析**：Fast Tracking = 串行改并行，不增加成本但增加风险；Crashing = 增加资源压缩工期，增加成本。Schedule Compression是两者的统称。

**第 5 题** 以下关于应急储备和管理储备的说法，正确的是？

A. 应急储备由项目发起人控制，管理储备由项目经理控制
B. 应急储备应对已知-未知风险，包含在成本基准内；管理储备应对未知-未知风险，不在成本基准内 ✅
C. 应急储备和管理储备都包含在成本基准内
D. 管理储备应对已识别风险，应急储备应对未识别风险

**解析**：应急储备（Contingency Reserve）应对Known-Unknown风险，在Cost Baseline内，由项目经理控制；管理储备（Management Reserve）应对Unknown-Unknown风险，在Cost Baseline外，需高层批准动用。

**第 6 题** 以下英文缩写与中文含义对应错误的是？

A. WBS — Work Breakdown Structure（工作分解结构）
B. CCB — Change Control Board（变更控制委员会）
