## 一、战略管理（大纲第16章）

### 1.1 战略管理的过程

```
战略分析 → 战略制定 → 战略实施 → 战略评价与控制
```

| 阶段 | 核心任务 | 常用工具 |
|------|------|------|
| **战略分析** | 分析内外部环境，识别机会与威胁 | SWOT分析、波特五力模型、PEST分析 |
| **战略制定** | 确定战略目标和战略方案 | BSC平衡计分卡、战略地图 |
| **战略实施** | 将战略转化为具体行动计划 | 项目管理、流程管理 |
| **战略评价** | 评估战略执行效果，及时调整 | KPI、BSC |

### 1.2 SWOT分析（高频考点）

**SWOT**：分析组织内外部环境的经典工具。

| 维度 | 说明 | 来源 |
|------|------|------|
| **S（Strengths，优势）** | 组织内部的有利因素 | 内部 |
| **W（Weaknesses，劣势）** | 组织内部的不利因素 | 内部 |
| **O（Opportunities，机会）** | 外部环境中的有利因素 | 外部 |
| **T（Threats，威胁）** | 外部环境中的不利因素 | 外部 |

**SWOT策略组合**：
- **SO策略**（增长型）：利用优势，抓住机会
- **ST策略**（多元化）：利用优势，规避威胁
- **WO策略**（扭转型）：克服劣势，抓住机会
- **WT策略**（防御型）：减少劣势，规避威胁

### 1.3 波特五力模型

**波特五力**：分析行业竞争格局的工具。

五种竞争力量：
1. **现有竞争者的竞争**：行业内企业之间的直接竞争
2. **潜在进入者的威胁**：新企业进入行业的可能性
3. **替代品的威胁**：其他产品替代本行业产品的可能性
4. **供应商的议价能力**：供应商对价格的控制力
5. **购买者的议价能力**：客户对价格的控制力

### 1.4 战略类型（波特竞争战略）

| 战略类型 | 说明 | 适用场景 |
|------|------|------|
| **成本领先战略** | 以最低成本提供产品/服务 | 价格敏感市场，规模经济 |
| **差异化战略** | 提供独特的产品/服务，获得溢价 | 品牌价值高，客户忠诚度高 |
| **集中化战略** | 专注于特定细分市场 | 利基市场，专业化服务 |

### 1.5 平衡计分卡（BSC）

**BSC（Balanced Scorecard）**：从四个维度衡量组织绩效的战略管理工具。

| 维度 | 核心问题 | 典型指标 |
|------|------|------|
| **财务维度** | 如何看待股东？ | 收入增长率、ROI、利润率 |
| **客户维度** | 如何看待客户？ | 客户满意度、市场份额、客户保留率 |
| **内部流程维度** | 哪些流程必须做好？ | 流程效率、质量指标、创新能力 |
| **学习与成长维度** | 如何持续改进？ | 员工满意度、培训时间、技术能力 |

> BSC的核心价值：将战略目标分解为可量化的指标，实现战略落地

### 1.6 战略与项目管理的关系

- 项目是实现战略的手段
- 项目组合管理确保项目与战略一致
- 项目集管理协调多个项目实现战略收益
- 项目经理需要理解组织战略，确保项目目标与战略一致

## 二、流程管理（大纲第18章）

### 2.1 流程管理基础

**业务流程**：为实现特定目标，将一系列相互关联的活动按照一定顺序组织起来的工作方式。

**流程管理**：对业务流程进行设计、执行、监控和优化的系统化管理活动。

### 2.2 流程分析工具

| 工具 | 说明 |
|------|------|
| **流程图（Flowchart）** | 用图形符号描述流程步骤和决策点 |
| **泳道图（Swimlane）** | 在流程图基础上增加角色/部门维度 |
| **价值流图（VSM）** | 识别流程中的增值和非增值活动 |
| **SIPOC图** | 供应商-输入-过程-输出-客户的全景视图 |

### 2.3 流程重构（BPR）vs 流程改进（BPI）

| 对比维度 | BPR（业务流程重构） | BPI（业务流程改进） |
|------|------|------|
| **变化幅度** | 根本性、彻底性变革 | 渐进式、持续性改进 |
| **目标** | 大幅提升绩效（50%以上） | 小幅持续改进（5-20%） |
| **风险** | 高风险 | 低风险 |
| **时间** | 较长（1-3年） | 较短（持续进行） |
| **代表方法** | BPR | PDCA、六西格玛、精益 |

> 记忆：BPR是"推倒重来"，BPI是"持续优化"

### 2.4 项目管理流程的优化

项目管理流程优化的目标：
- 减少不必要的审批环节
- 提高流程执行效率
- 确保流程的标准化和可重复性
- 持续改进项目管理能力

## 三、信息系统安全管理深化（大纲第22章）

### 3.1 PKI公开密钥基础设施

**PKI（Public Key Infrastructure）**：基于公钥密码技术，提供数字证书服务的安全基础设施。

**PKI的核心组件**：
- **CA（证书颁发机构）**：负责颁发、管理和撤销数字证书
- **RA（注册机构）**：负责验证用户身份，向CA申请证书
- **数字证书**：绑定用户身份和公钥的电子文件
- **证书库**：存储和发布证书的目录服务

**数字证书的生命周期**：
申请 → 审核 → 颁发 → 使用 → 更新/撤销

**信任模型**：
- **层次信任模型**：根CA → 中间CA → 终端实体（树形结构）
- **交叉认证模型**：不同PKI体系之间互相信任

### 3.2 PMI权限管理基础设施

**PMI（Privilege Management Infrastructure）**：管理用户权限（授权）的基础设施，与PKI配合使用。

**PMI vs PKI的区别**：
- PKI：解决**身份认证**问题（你是谁？）
- PMI：解决**授权管理**问题（你能做什么？）

**属性证书（AC）**：PMI中用于描述用户权限的证书，类似于PKI中的公钥证书，但存储的是权限信息而非公钥。

**访问控制模型**（已在单元03覆盖，此处补充）：
- **ABAC（基于属性的访问控制）**：根据用户属性、资源属性和环境条件动态决定访问权限，比RBAC更灵活

### 3.3 信息安全系统工程（ISSE）

**ISSE（Information Security Systems Engineering）**：将安全工程原则应用于信息系统开发的方法论。

**ISSE-CMM（信息安全系统工程能力成熟度模型）**：
- 评估组织信息安全工程能力的成熟度
- 共5个成熟度级别（与CMMI类似）

**ISSE过程**：
1. 发现信息保护需求
2. 定义系统安全需求
3. 设计系统安全架构
4. 开发详细安全设计
5. 实施系统安全
6. 评估信息保护有效性

### 3.4 信息安全审计

**信息安全审计**：对信息系统的安全策略、控制措施和操作记录进行独立检查和评估。

**审计的主要内容**：
- 访问控制审计（谁访问了什么资源）
- 操作日志审计（系统操作记录）
- 安全事件审计（安全事件的记录和分析）
- 合规性审计（是否符合安全策略和法规要求）

**审计日志的要求**：
- 完整性：不可篡改
- 可追溯性：能追溯到具体操作人
- 时效性：及时记录

## 四、高频考点汇总

1. **SWOT分析**：S/W是内部因素，O/T是外部因素
2. **BSC四维度**：财务、客户、内部流程、学习与成长
3. **BPR vs BPI**：BPR是根本性变革，BPI是渐进式改进
4. **PKI**：解决身份认证（你是谁），PMI解决授权（你能做什么）
5. **CA**：证书颁发机构，负责颁发和管理数字证书
6. **信息安全审计**：独立检查安全策略和控制措施的执行情况

---

## 五、易错点

- ❌ SWOT中机会和威胁是内部因素 → ✅ 机会和威胁是**外部**因素，优势和劣势是内部因素
- ❌ BPR和BPI都是渐进式改进 → ✅ BPR是**根本性变革**，BPI才是渐进式改进
- ❌ PKI解决授权问题 → ✅ PKI解决**身份认证**，PMI解决**授权管理**
- ❌ BSC只关注财务指标 → ✅ BSC有**四个维度**，财务只是其中之一
